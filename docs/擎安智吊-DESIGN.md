# 擎安智吊 UI Design System

## 品牌定位

- 产品名称：擎安智吊。
- 产品类型：吊装安全运营与智能监测平台。
- 品牌标识：沿用现有 `project/frontend-vue/public/logo-512.png` 的蓝金盾形 Logo。
- 核心气质：工业、精确、可信、安全关键、现代中国企业软件。

## 视觉方向

- 画布以 1920 × 1080 桌面运维场景为主。
- 延续现有项目的深海军蓝侧边栏和顶栏、深灰蓝工作区、电光蓝与青色高亮。
- 使用与 Logo 呼应的安全金色作为克制的强调色；红色只用于严重告警，绿色只用于在线与健康状态。
- 避免紫色渐变、过度圆角、重度玻璃拟态、消费级插画、Emoji 和装饰性过强的视觉。
- 信息密度偏高，但通过明确分区、网格、数值层级与状态标签保证控制室环境下的可读性。
- 面板采用 1px 蓝灰描边、2–4px 小圆角、轻微内高光；实时和选中状态可使用克制的青色辉光。
- 背景允许加入低对比度技术网格、蓝图线条和雷达扫描纹理。

## 字体

- 中文界面：Noto Sans SC / 思源黑体。
- 数字遥测：DIN Alternate / Roboto Condensed。
- 标题采用中粗字重与紧凑字距，正文以 13–14px 为主。
- 核心数值采用 26–34px 和等宽数字。

## 布局

- 左侧导航宽 232px，展示实际 Logo 与“擎安智吊”。
- 顶部状态栏高 60px，容纳项目/场站选择、天气与时间、系统健康、通知和用户信息。
- 主工作区采用 12 栏网格、16px 栏间距、16–20px 页面内边距。
- 工作台以中央实时吊装场景或数字孪生为核心，周围布置 KPI、设备健康、告警流、风险趋势和任务进度。
- 管理类页面统一采用“筛选工具栏 + 内容面板 + 分页”的结构。

## 组件语言

- KPI 卡片：标签、大数值、趋势、微型折线或状态环。
- 状态标签：在线绿色、预警琥珀、离线灰蓝、告警红色。
- 图表：细网格线，蓝/青主序列，金色对比序列。
- 表格：44px 紧凑行高、吸顶表头、明显的风险级别标记。
- 地图与视频：深色控制条、青色识别框、金色吊装轨迹、红色危险区域。
- 图标统一使用 Lucide 风格线性图标，不使用 Emoji。

## 可访问性

- 文本与背景对比至少达到 WCAG AA。
- 风险等级不得只依赖颜色，还需要图标、文字或形状辅助表达。
- 键盘焦点使用青色可见描边。
- 动画控制在 300ms 内，并支持减少动态效果。
